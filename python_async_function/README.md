
# Python - Async

## Description
This project covers asynchronous programming in Python using the asyncio module.

## Learning Objectives
- Understand async and await.
- Write and execute asynchronous coroutines.
- Run multiple coroutines concurrently.
- Create asyncio tasks.
- Measure execution time.
- Use random.uniform() to generate random delays.

## Requirements
- Python 3.8
- Ubuntu 20.04 LTS
- pycodestyle 2.5.x

## Tasks
- **0:** Basic async syntax
- **1:** Concurrent coroutines
- **2:** Measure runtime
- **3:** Create asyncio tasks
- **4:** Concurrent tasks
